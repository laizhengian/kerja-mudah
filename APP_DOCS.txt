========================================
  KERJA MUDAH - TECHNICAL DOCUMENTATION
========================================

OVERVIEW
--------
Kerja Mudah is an offline desktop application for small business shops in Malaysia. Built with Python + Tkinter, packaged as a single .exe file. Can be placed in any folder.

Perfect for:
- Phone repair shops
- Car detailing shops
- Electronics repair shops
- Any service-based business

Tech Stack: Python 3.14, Tkinter (GUI), SQLite (database), fpdf2 (PDF generation), PyInstaller (packaging)

---

FILE STRUCTURE
--------------
Kerja Mudah/
    main.py              Main application (all UI + logic)
    database.py          SQLite database layer
    keygen.py            License key generator (SECRET - seller only)
    get_hwid.py          HWID display tool (for customers)
    Start.bat            Easy launcher for customers
    EULA.txt             End User License Agreement
    README.txt           Customer user guide
    APP_DOCS.txt         This file (technical docs)
    data/
        data.db          SQLite database (auto-created)
        invoices/        Generated PDF invoices stored here
    dist/
        Kerja Mudah.exe  Packaged executable

Note: The app can be placed in any folder. All data is stored relative to the app location.

DATABASE SCHEMA (SQLite)
------------------------

Settings Table
  Key-value store for all app configuration.

  Column   Type      Description
  -------- --------- -------------------------
  key      TEXT (PK) Setting name
  value    TEXT      Setting value

  Stored settings:
  - business_name    Business name
  - business_phone   Business phone (+60...)
  - business_email   Business email
  - google_review    Google review link (for invoices)
  - language         UI language (en/ms/zh)
  - setup_complete   Whether wizard was completed
  - pin_hash         SHA-256 hash of PIN (optional)
  - licensed_hwid    Licensed hardware ID
  - license_key      License key
  - install_date     Demo install date
  - invoice_format   "text" or "pdf"
  - network_path     Shared folder path for sync
  - invoice_title    Custom invoice title (default: "INVOICE")
  - payment_terms    Payment terms text (default: "Payment due within 7 days")
  - thank_you_note   Thank you message (default: "Thank you for your business!")
  - footer_text      Invoice footer text

Customers Table
  Column     Type      Description
  ---------- --------- -------------------------
  id         INTEGER (PK) Auto-increment
  name       TEXT      Customer name
  phone      TEXT      Phone (+60...)
  email      TEXT      Email address
  address    TEXT      Address (unused)
  notes      TEXT      Notes
  created_at TIMESTAMP Creation time

Jobs Table
  Column       Type      Description
  ------------ --------- -------------------------
  id           INTEGER (PK) Auto-increment
  customer_id  INTEGER (FK) References customers.id
  job_code     TEXT (UNIQUE) Auto-generated: JOB-YYYYMMDD-N
  item         TEXT      Item being repaired
  problem      TEXT      Problem description
  quote        REAL      Price quote (RM)
  status       TEXT      pending / in-progress / done
  due_date     TEXT      Due date
  notes        TEXT      Notes
  created_at   TIMESTAMP Creation time
  completed_at TIMESTAMP When marked done

Invoices Table
  Column         Type      Description
  -------------- --------- -------------------------
  id             INTEGER (PK) Auto-increment
  job_id         INTEGER (FK) References jobs.id
  invoice_code   TEXT (UNIQUE) Auto-generated: INV-YYYYMMDD-N
  amount         REAL      Invoice amount (RM)
  paid           INTEGER   0 = unpaid, 1 = paid
  payment_method TEXT      Cash / E-Wallet / Card / Transfer
  created_at     TIMESTAMP Creation time

  Note: Paid invoices older than 7 days can be cleaned up from Settings.

Appointments Table
  Column       Type      Description
  ------------ --------- -------------------------
  id           INTEGER (PK) Auto-increment
  customer_id  INTEGER (FK) References customers.id
  date         TEXT      Appointment date
  time         TEXT      Appointment time
  purpose      TEXT      Purpose
  status       TEXT      scheduled / done
  notes        TEXT      Notes

APP FLOW
--------

First Launch
  1. License check -> If no license, show activation screen
  2. Demo mode check -> 7 day trial, 10 job limit
  3. Setup wizard -> Business name, phone, email, language
  4. Optional PIN setup
  5. Main dashboard

PIN System (Optional)
  - Owner can set a 4-digit PIN in Settings
  - PIN is SHA-256 hashed before storing
  - Required to access Settings (edit business info)
  - Can be changed or removed from Settings

Job Workflow
  1. Create job -> Select/create customer, fill item/problem/quote
  2. Job appears in Jobs list with status "pending"
  3. Can change to "in-progress"
  4. Can edit job details at any time
  5. When done -> Click "Done" -> Shows invoice options:
     - Invoice + WhatsApp (sends text to customer)
     - Invoice + Email (opens email client)
     - Just Invoice (creates record only)
     - Skip

Customer Management
  - Add customers with name, phone, email, notes
  - Edit customer details at any time
  - Search/filter customers in the list
  - Customers auto-linked when creating jobs

Appointment Management
  - Schedule appointments with date, time, purpose
  - Edit appointments at any time
  - View today's appointments on dashboard

Invoice System
  - Auto-generated codes: INV-YYYYMMDD-N (N = daily counter)
  - Linked to a job via job_id
  - Two formats: Text (plain message) or PDF (professional)
  - Can be sent via WhatsApp or Email
  - Download PDF directly from invoice list
  - Mark as paid with payment method (Cash/E-Wallet/Card/Transfer)
  - Paid invoices auto-deleted after 7 days

PDF Invoice Generation
  - Uses fpdf2 library
  - Stored in data/invoices/ folder
  - Filename: {invoice_code}.pdf (e.g., INV-20260810-001.pdf)
  - Contains: Business info, customer info, item table, total, footer
  - Can be downloaded from Invoices and Jobs sections

Edit Capability
  All main entities can be edited after creation:
  - Jobs: Edit item, problem, quote, status, due date, notes
  - Customers: Edit name, phone, email, notes
  - Appointments: Edit date, time, purpose, status, notes

Field Validation
  Input validation is enforced across all forms:
  - name_field(): Blocks <>(){}[]|\' characters in names
  - phone_field(): Digits and + only, max 15 chars
  - pin_field(): Digits only, max 4 chars, displays as * 
  - email_field(): Blocks <>(){}[]|\' characters
  - date_field(): Digits and hyphens only, YYYY-MM-DD format
  - number_field(): Digits and decimals only
  - search_field(): Gray placeholder text, clears on focus
  - Required fields: Customer name + Item required for new jobs

Date Format
  All dates displayed as: 10 August 2026 format

License System
  - HWID = SHA-256(node + processor + MAC)[:16]
  - Key = SHA-256(HWID)[:20]
  - Key is validated on startup
  - Generator in keygen.py (seller only)
  - get_hwid.py shows customer's HWID

Network Sync (Planned)
  - Future feature: Sync via shared folder on WiFi
  - Not yet implemented in the UI
  - Database supports network_path setting for future use

Backup/Restore
  - Backup: Copies data/data.db to user-selected location
  - Restore: Replaces current database with backup file
  - CSV Export: Exports customers, jobs, invoices to CSV files

Open on Startup
  - Toggle in Settings to open app on Windows startup
  - Creates a .bat file in Windows Startup folder
  - Can be enabled/disabled at any time

UI FEATURES
-----------

Scrollable Interface
  - All pages use Canvas + Scrollbar for scrolling
  - Content scrolls when window is small
  - Scroll position resets when changing pages
  - Mousewheel binds on hover over content area only
  - Demo mode banner stays fixed at top of content area

Responsive Design
  - Font sizes adapt based on window width
  - Smaller windows get slightly smaller fonts to prevent cutoff
  - Content stays readable across different screen sizes

Inline Search
  - Jobs, Customers, Appointments, and Invoices have search bars
  - Type to filter results in real-time
  - No need to click a button
  - Placeholder text shows what to search for

Dashboard
  - Active jobs count
  - Today's appointments
  - Outstanding amount (unpaid invoices)
  - Completed jobs count
  - Reminders for due/overdue jobs
  - Quick action buttons

TRANSLATION SYSTEM
------------------

Three languages supported:
  - English (en) - Default
  - Bahasa Malaysia (ms)
  - Chinese (zh)

Translations stored in T dictionary in main.py. Language selectable in Setup Wizard and Settings. Uses self.t("key") to get translated text.

IMPORTANT NOTES
---------------

  1. Offline only          - No internet required, no cloud sync
  2. Single file database  - All data in data/data.db
  3. No auto-updates       - Each version is manually distributed
  4. PIN is optional       - App works without PIN
  5. Demo mode             - 7 days, 10 jobs max, shows yellow banner
  6. PDF storage           - data/invoices/ folder (not synced)
  7. WhatsApp links        - Opens wa.me/phone?text=message
  8. Email                 - Opens mailto: link with pre-filled content
  9. Portable              - Can be placed in any folder
  10. Auto-cleanup         - Paid invoices older than 7 days can be cleaned from Settings
